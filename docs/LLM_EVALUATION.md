# Frozen champion/challenger evaluation (KIW-26)

`kiwit.llm.evaluation.freeze_corpus` creates a checksum-bound corpus containing context gold labels and critic outcomes separately from point-in-time model inputs. It validates both strict role input contracts, evidence timing and outcome timing. The caller supplies historical/paper evidence and net returns already incorporating fees/slippage; no market data or outcomes are invented. Corpus metadata identifies the source version and validation/test/walk-forward split. The split label alone is not proof that humans have never used those scenarios for tuning.

`compare_models` runs at least two independently configured ContextAnalyst/TradeCritic pairs on identical frozen inputs, with repeated calls. Reports bind corpus fingerprints, complete model/provider configuration, prompt versions and outputs. `save_artifact` persists checksum-addressed immutable corpus/report JSON. Raw model calls need not be reproducible because providers can be nondeterministic; frozen inputs and recorded outputs allow metrics to be reconstructed. Repeated runs explicitly report consistency.

The combined report includes context recall/false alarms, quant-conflict accuracy and schema compliance; critic net expectancy, profit factor, unit-equity drawdown, losing trades rejected, winning trades falsely rejected, NO_TRADE loss fraction, schema failures, consistency, latency and usage. Known critic costs are grouped by UTC date and per evaluation; unknown charges are counted separately. Context costs remain separately reported. These are research diagnostics using supplied returns and non-overlapping selected trades, not approved portfolio P&L. Semantic hallucination rate remains explicitly unmeasured until independent reviewers adjudicate evidence; malformed responses and unsupported source IDs are blocked, but are not substituted for a semantic hallucination rate.

DeepSeek V4 remains runtime default. Configure the champion's actual API adapter/model ID independently; the GPT-5.6 Sol label does not authorize a provider switch. Reports always set NOT_AUTHORIZED for promotion and list untouched out-of-sample/walk-forward evidence, statistically credible net improvement, paper/shadow validation and human approval as prerequisites. No public benchmark score, inferred confidence or report field activates/rolls back a model automatically.

The combined test suite covers missing evidence, timestamps, conflicts, strict schemas, invented source IDs, malformed replies, repeated consistency and an injected news instruction attempting to create an order. The adversarial fixture proves the deterministic schema boundary rejects the attempted order; it does not claim a real provider is immune to prompt injection.

Implementation was verified with synthetic scenarios and fake providers. A real historical/paper corpus, paid DeepSeek-versus-champion runs, hallucination adjudication, paired statistical analysis and shadow validation remain pending. No real benchmark superiority or promotion claim has been made.
